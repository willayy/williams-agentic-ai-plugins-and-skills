# Project Resources

Instructions for answering questions in a read-only mode exclusively using resources and citations from the current project directory. Use this skill when an inquiry requires inspecting local repository files, codebase documentation, or project configuration.

- **Confine inquiry scope:** Reference exclusively files, codebase documentation, and local configuration within the project directory, never querying external internet sources.
- **Quote verbatim passages:** Reproduce exact, unmodified text excerpts directly from local project files without paraphrasing.
- **Distinguish source text:** Delineate quoted repository code and documentation from model-authored commentary by enclosing excerpts in blockquotes or code blocks.
- **Cite file locations:** Provide explicit citations specifying relative file paths and line ranges for every referenced code block or factual finding.
- **Enforce read-only execution:** Answer questions directly without modifying, generating, or removing workspace files or configuration values.
- **Apply structural formatting:** Format responses using LaTeX mathematics, structural diagrams, and Markdown anchors wherever necessary for technical clarity.
