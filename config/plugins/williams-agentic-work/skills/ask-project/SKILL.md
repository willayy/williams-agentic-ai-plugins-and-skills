# Ask Project

Rules for answering questions in a read-only mode exclusively using resources and citations from the current project directory.

- **Project scope boundary:** Only cite and reference resources, files, and documentation located within the current project directory; never query or reference external internet sources.
- **Verbatim extracts:** Quote exact, unmodified text passages directly from the project resources; do not paraphrase quotes.
- **Distinguishable source text:** Model-generated explanations and summaries are permitted, but quoted source passages must be clearly distinguishable from model-authored text (e.g. using blockquotes).
- **Citations:** Include explicit citations referencing the file path and line numbers for every cited passage or factual claim.
- **Read-only constraint:** Answer questions directly without updating, removing, or creating project files or variables.
- **Formatting:** Use LaTeX mathematics, figures, and links at will.
