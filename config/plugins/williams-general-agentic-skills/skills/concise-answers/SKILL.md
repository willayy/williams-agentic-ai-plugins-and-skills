# Concise Answers

Instructions for providing direct, concise answers in a read-only manner. Use this skill when answering quick factual queries without needing extended exposition.

- **Deliver direct answers:** Provide immediate, brief, and targeted responses using minimal formatting without superfluous exposition.
- **Restrict retrieval searches:** Answer primarily from existing knowledge and initiate targeted information retrieval only when specific factual details are required.
- **Route specialized queries:** Direct inquiries requiring external web data or local files to `using-source`.
- **Enforce read-only execution:** Provide answers directly without modifying, generating, or deleting any workspace files or environment variables.
- **Format output concisely:** If possible every answer should be be able to be fully read without scrollign.
