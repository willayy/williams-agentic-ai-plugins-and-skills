# Issue Diagnosis

Instructions for diagnosing software issues, determining their underlying root causes, and specifying verifiable fixes. Use this skill when an error, unexpected failure, bug, or regression is encountered.

1. **Document observed symptoms:** Detail the exact failure mode, unexpected behaviors, and error messages observed during the incident.
2. **Isolate root causes:** Identify the underlying defect, invalid assumption, or broken state transition that triggered the observed failure.
3. **Formulate concrete remediations:** Propose an actionable, minimal, and verifiable solution that directly resolves the root cause without introducing regressions.
