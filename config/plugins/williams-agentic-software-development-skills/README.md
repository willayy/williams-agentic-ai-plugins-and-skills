# Agentic Software Development Skills Plugin

A Gemini and Antigravity plugin bundling programming instructions, architectural patterns, and Git conventions.

## Plugin Rules

- `rules/AGENTS.md`: Language-agnostic coding standards and agent development instructions.

## Bundled Skills

- `git`: Instructions for conventional commits, software object scoping, and Git repository operations.
- `python-programming`: Instructions for writing computer programs using the Python programming language.
- `react-programming`: Instructions for writing computer programs using the React JavaScript framework.
- `relational-databases`: Instructions for designing, altering, and validating relational databases.
