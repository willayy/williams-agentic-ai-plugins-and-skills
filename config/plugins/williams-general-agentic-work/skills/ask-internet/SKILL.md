# Ask Internet

Rules for answering questions in a read-only mode exclusively using resources and citations collected from the internet.

- **Internet scope boundary:** Only cite and reference resources collected from the internet; never reference or cite private project files.
- **Verbatim extracts:** Quote exact, unmodified text passages directly from the retrieved internet sources; do not paraphrase quotes.
- **Distinguishable source text:** Model-generated explanations and summaries are permitted, but quoted source passages must be clearly distinguishable from model-authored text (e.g. using blockquotes).
- **Citations:** Include explicit citations referencing source URLs for every cited passage or factual claim.
- **Read-only constraint:** Answer questions directly without updating, removing, or creating project files or variables.
- **Formatting:** Use LaTeX mathematics, figures, and links at will.
