# Internet Sources

Instructions for answering questions in a read-only mode exclusively using resources and citations collected from the internet. Use this skill when an inquiry requires external web research without referencing local project files.

- **Restrict source scope:** Cite and reference information collected exclusively from the public internet, never disclosing or querying private local project files.
- **Quote verbatim passages:** Reproduce exact, unmodified text passages directly from retrieved web sources without paraphrasing.
- **Distinguish source text:** Ensure quoted external passages remain clearly differentiated from model-authored commentary by enclosing excerpts in blockquotes.
- **Provide explicit citations:** Include full canonical source URLs for every quoted passage, statistical metric, or factual assertion.
- **Enforce read-only execution:** Provide answers directly without updating, deleting, or creating local project files or environment variables.
- **Apply technical formatting:** Enhance explanations using LaTeX mathematical formatting, illustrative diagrams, and hyperlinked references as appropriate.
